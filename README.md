# Kura
**現在、Discordの動画埋め込みの仕様変更により、使えない可能性があります。**

## 1. 作品コンセプト・内容
### 概要
「Kura」はDiscord上で10MB以上の動画や画像/ファイルを共有するためのWebサービスです.\
 Discordでは本来, 10MB以上の動画や画像は送信できず, ギガファイル便やDropboxで共有する場合はそのサイトを閲覧する必要がありました. ただ「Kura」ではOGPを用いて, Discord上で動画や画像を埋め込み, サイトを閲覧しなくても, Discord上で動画や画像を閲覧することを可能にします.

 ### 背景と課題
Discordでは通常, 大容量の動画や画像を直接送信することができず, 外部の共有サービス（ギガファイル便やDropbox等）を利用する必要があります.しかし, それらは「リンクをクリックして別サイトに移動し, ダウンロードする」という手間が発生し, チャットの流れを止めてしまったり, 大量の広告にうんざりするという課題がありました.

### 解決策
「Kura」はOGP(Open Graph Protocol) 技術を駆使し, Discord上での再生・表示に特化した設計を行いました. たとえDiscord自体のアップロード制限を超えるサイズであっても, Kuraにアップロードしてリンクを貼るだけで,Discord内で直接動画の視聴や画像の閲覧が可能になります.

### 本作品の意義
サイトを閲覧する手間を省き, 「閲覧する人がチャット画面から離れずにコンテンツを楽しむ」というユーザー体験を提供します.

### 技術的な苦労・テクニック
1. チャンクアップロードによる大容量送信の実現\
Cloudflare Tunnelには, クライアントのアップロードサイズの上限が1リクエスト100MBまでという制限があります. これを回避するために, クライアント側で50MBごとにデータを分割して送信, サーバ側で結合するようにしています.

2. ファイルパスの隠蔽と直接アクセス攻撃の防止\
悪意のある実行ファイルがアップロードされ, URLから直接パスを指定して不正実行されるリスクを防ぐため, 物理ストレージ上の保存ファイル名と, ユーザーに公開するファイルID（UUID）を完全に分離しました. ファイルの閲覧やダウンロードの際は, 必ずデータベースを経由して実ファイルに紐付ける設計とし, 堅牢なセキュリティを担保しています.

3. 初めてのフルスタック・DB設計への挑戦\
今回「Kura」の構想を実現するためには, フロントエンドだけでなく, バックエンドの構築やデータベースによる複雑な状態管理が不可欠でした. これまで経験のなかったGo言語によるAPI開発や, PostgreSQLを用いたデータベースの設計, さらにはDockerやCloudflareを利用したインフラ構築まで, すべてゼロから学習し 一人でフルスタックの開発を完遂したことが, 本プロジェクトにおける最大の挑戦であり, 個人的な大きな成長に繋がりました.
